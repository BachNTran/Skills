# Preferences

Durable, project-local record of how this developer likes systems built — it **grows over
time** so the project gets smarter about your taste. The `SessionStart` hook injects the
**Active preferences** digest each session; the agent appends here when it learns a
preference (a stated taste, or a correction it received) at milestones and after you correct
it. Keep entries short and imperative.

> Project-local on purpose: a globally-installed skillset keeps each project's preferences
> here, in the project — never in the shared skills dir.
